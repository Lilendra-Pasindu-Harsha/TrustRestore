Technical Foundation

Tri-Factor Trust Mathematical Framework

How TrustRestore computes per-pixel confidence and selectively applies edge-preserving bilateral filtering without degrading high-confidence neural details.

1

Data Fidelity Trust

T_data = exp( - (I_rest - I_obs)² / (2 σ_n² + ε) )

Measures photometric consistency between deep restoration and the observed image. Noise sigma σ_n is estimated dynamically via Median Absolute Deviation (MAD).

2

Structural Gradient Trust

T_struct = exp( - (∇I_rest - ∇I_obs)² / (2 σ_g² + ε) )

Extracts gradient magnitude vectors using 3×3 Sobel operators. Penalizes spurious edge hallucinations generated by generative deep models.

3

Stability Uncertainty Trust

T_stab = exp( - Var_MC / (P_95(Var_MC) + ε) )

Executes K=20 stochastic forward passes with Monte Carlo Dropout enabled. Regions with high variance denote low epistemic certainty.
